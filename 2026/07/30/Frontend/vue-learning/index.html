1.变量类型分为基础类型(原始类型)和引用类型(对象类型),分别是哪些? 区别是什么? 基础类型: Number、String、Boolean、Null、Undefined、Symbol 引用类型: Object、Array、Function、Date、RegExp 区别: 基础类型是存放在栈中,引用类型是存放在堆中 值的比较: 基础类型是直接比较值,引用类型是比较引用地址12345678// 基础类型const a = 10;const b = 10;console.log(a === b); // true// 引用类型const c = { a: 10 };const d = { a: 10 };console.log(c === d); // false 赋值(复制)行为: 基础类型是直接赋值,引用类型是赋值引用地址12345678// 基础类型const a = 10;const b = a;console.log(b); // 10// 引用类型const c = { a: 10 };const d = c...
